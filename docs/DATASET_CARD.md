# 数据说明：dacl10k 五类检测子任务

## 来源

- 维护者仓库：https://github.com/phiyodr/dacl10k-toolkit
- 原论文：Flotzinger, Rösch, Braml, WACV 2024。
- 镜像：https://huggingface.co/datasets/Voxel51/dacl10k
- 固定 revision、元数据 SHA256 和许可依据：`configs/sources.json`。

镜像包含 8,922 个样本，其中有标注的原始训练/验证划分为 6,935 / 975，另有 1,012 个 testdev 图像。镜像不包含原始数据完整的 998 个 testchallenge 图像。代码只从有标注的 train 和 validation 中建立训练与验证集。

## 任务定义

| 新类别 | 原类别 | 说明 |
|---|---|---|
| crack | Crack | 图像可见裂缝 |
| spalling | Spalling | 混凝土剥落 |
| exposed_rebar | ExposedRebars | 露筋 |
| rust | Rust | 锈蚀与锈迹 |
| rockpocket | Rockpocket | 蜂窝麻面 / 骨料孔洞 |

不将 Bearing / EJoint 等构件标签解释为位移或异常，不将单张普通照片转换成毫米量测。`ACrack` 也不悄悄并入 Crack；类别定义保持可追溯。

使用镜像 `od_ground_truth` 的归一化左上角 xywh，转换成 YOLO 中心 xywh。框来自原始语义多边形的包围框，不是重新人工标注的独立病害实例。不同类别允许重叠。

对越界框进行裁切并计数，丢弃非有限值、非正尺寸或不足一像素的无效框。类别之外的标注不作为本子任务的正例；没有这五类标注的图片保留为空标签负样本。

## 划分与污染检查

1. 原始 train 和 validation 标签保持不变。
2. 预实验按 `SHA256(seed:filename)` 排序选取 768 / 160 张，不按识别效果选图。
3. 从固定仓库版本下载，校验 Git blob SHA1 或 LFS SHA256，同时记录每张图片的 SHA256 和原始尺寸。
   训练图片使用独立副本；如 JPEG 最终 EOI 后有额外字节，仅裁去尾部而不改变像素。清单分别保留原始哈希、准备哈希和变换类型，防止训练库的自动修复破坏原始文件。
4. 相同图片哈希只保留一份，优先保留验证图；移除记录列入 `quarantined`。
5. dHash 跨划分距离不大于 2 的样本仅作为人工复核候选，不自动当作已确认重复。
6. 非恒等 EXIF 方向的图片在坐标系确认前隔离。当前隔离两张训练图，实际使用 **766 张训练图 / 160 张验证图**；原始划分和其余标签不变。

图像哈希不能证明桥梁身份、连续拍摄序列或地理位置完全隔离。论文最终实验应补充跨桥梁、跨来源或独立采集测试。当前不报告独立测试集或官方挑战榜单分数。

## 已知局限

类别不均衡、粗多边形标注、细裂缝尺度、光照和巡检角度差异都会影响模型。预实验的小样本结果只能说明当前实验条件；未经人工复核的高分预测也不等于病害已经确认。
